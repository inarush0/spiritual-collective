# spiritual-collective

## Agent skills

### Issue tracker

Issues live as GitHub issues in `inarush0/spiritual-collective`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using their default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Specification

`docs/spec/` holds the implementation-ready specification for the first release; start at `docs/spec/README.md`. It is authoritative for what to build. `CONTEXT.md` is the glossary and the spec does not redefine its terms; `docs/adr/` holds the two hard-to-reverse decisions.
